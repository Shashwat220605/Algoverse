# Algorithm contribution guide

When adding an algorithm or visualization to AlgoVerse, keep the implementation and explanation aligned.

## Checklist

- Define the algorithm and its expected input/output.
- Keep the implementation focused and readable.
- Add or update the visualization so it reflects the actual algorithm state.
- Cover edge cases such as empty input, duplicate values, and already-sorted input where relevant.
- Verify controls work with both small and representative inputs.
- Explain time and space complexity in the documentation.

## Pull request

Describe the algorithm, visualization changes, validation performed, and any known limitations. Keep unrelated UI or refactoring changes out of the same pull request.
