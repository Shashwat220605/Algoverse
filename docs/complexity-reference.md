# Complexity reference

Use this quick reference when documenting algorithm visualizations.

| Pattern | Typical time | Typical space |
|---|---:|---:|
| Linear scan | O(n) | O(1) |
| Binary search | O(log n) | O(1) iterative |
| Comparison sort | O(n log n) average | Depends on implementation |
| Hash lookup | O(1) average | O(n) |
| BFS/DFS | O(V + E) | O(V) |

Complexity should describe the actual implementation rather than the textbook algorithm alone.
