# Contributing to AlgoVerse

AlgoVerse is an interactive DSA learning workspace focused on connecting algorithm code with visual execution.

## Pull requests

Keep changes focused and describe the algorithm, visualization, or learning experience being improved.

Before opening a pull request:

1. Run `npm install` if dependencies are needed.
2. Run `npm run build` to verify the production build.
3. Explain the change and testing performed in the pull request.

## Security

Never commit API keys, passwords, `.env` files, or other secrets.
