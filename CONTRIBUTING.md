# Contributing to AlgoVerse

Thanks for helping improve AlgoVerse, an interactive DSA learning platform.

## Development workflow

1. Create a focused branch from `main`.
2. Install dependencies with `npm install`.
3. Run the development server with `npm run dev`.
4. Verify production builds with `npm run build` when your change affects the application.
5. Open a pull request describing what changed and how it was tested.

## Algorithm changes

When adding or modifying an algorithm, keep the implementation, execution steps, visualization state, code highlighting, explanation, and complexity information consistent where applicable.

## UI changes

Keep the interface responsive and preserve the existing learning flow. Test navigation and the relevant algorithm workspace before opening a pull request.

## Pull requests

Keep pull requests focused. Include a concise summary, testing notes, and screenshots or recordings for meaningful visual changes.

## Security

Never commit API keys, credentials, `.env` files, or other secrets.
